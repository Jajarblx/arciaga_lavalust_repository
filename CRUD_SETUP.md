# Laboratory Exercise No. 5: Product CRUD with Authentication

This project uses the APIs available in LavaLust 4.6.0 to implement session authentication and a protected product inventory CRUD module. The users table is an authentication source; products are the CRUD subject.

## Routes

| Method | Route | Purpose |
|---|---|---|
| GET | `/` | Redirect to login or products |
| GET | `/login` | Show login form |
| POST | `/login` | Authenticate |
| GET | `/logout` | End the session |
| GET | `/products` | List products |
| GET/POST | `/products/create` | Show form/create product |
| GET/POST | `/products/edit/{id}` | Show form/update product |
| GET/POST | `/products/delete/{id}` | Confirm/delete product |

All product routes use `AuthMiddleware` and redirect unauthenticated requests to `/login`.

## Local setup

1. Start Apache and MySQL in XAMPP.
2. Import `database/local_setup.sql` in phpMyAdmin, or run it with the MySQL client.
3. Copy `.env.example` to `.env` if `.env` is absent and update the values for your machine.
4. Open `http://localhost/ArciagaLavalust/login`.

No login credentials are committed or seeded. Create an administrator in the
`users` table with a password generated by PHP's `password_hash()` function.
Authentication checks that hash with `password_verify()`.
